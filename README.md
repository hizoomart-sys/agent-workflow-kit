# Agent Workflow Kit

**Session persistence, parallel git worktrees, safety guards and a second opinion from Codex for Claude Code.**

Плагин для Claude Code, который решает четыре вещи:

- **работа не теряется после `/clear`:** новая сессия сама получает, где остановились и какой следующий шаг;
- **несколько задач идут параллельно и не мешают друг другу:** у каждой сессии своя ветка и своя рабочая копия;
- **агент не выдаёт непроверенное за готовое и не делает опасного с git:** такие действия блокируются до выполнения, а не запрещаются строчкой в инструкции;
- **решение можно проверить чужими глазами:** Codex и, по желанию, Gemini отвечают на тот же вопрос независимо, Claude выбирает ответ с обоснованием.

Инструкции полезны, но не гарантируют соблюдения в каждом ходе агента. Поэтому всё критичное здесь сделано хуками, которые останавливают действие.

## Требования

- Claude Code с поддержкой плагинов
- macOS, Linux или WSL; на обычной Windows не работает (хуки написаны на bash)
- `git`, `python3` 3.9+, `node`
- для второго мнения: [Codex CLI](https://github.com/openai/codex) с входом через подписку ChatGPT (`codex login`), `jq`, `curl`; Gemini по желанию

## Установка

В Claude Code:

```
/plugin marketplace add hizoomart-sys/agent-workflow-kit
/plugin install agent-workflow-kit@agent-workflow-kit
```

После установки плагин появится в `/plugin` на вкладке Installed.

## Попробовать за 2 минуты

1. В любом git-проекте попросите Claude поправить что-нибудь, затем напишите: «сохраняемся».
2. Claude запишет `.planning/RESUME.md` и выдаст блок «продолжаем …».
3. Выполните `/clear`.
4. Новая сессия начнёт с карточки:

```
[SESSION RESUMED after clear]
RESUME.md found. Do NOT ask what to do — continue immediately.

Session: правка формы входа
Status: in_progress
Next step: запустить tests/login.test.js и проверить ошибку при пустом пароле
```

Чтобы проверить барьер, попросите Claude: «сделай git reset --hard». Команда будет заблокирована с объяснением.

## Что вы получите

### Сессии
- **Сохранение одной фразой:** «сохраняемся», «сохрани сессию» или «save session». Пишется блок в `.planning/CONTEXT.md` и карточка `.planning/RESUME.md`, старые блоки уходят в архивы по месяцам.
- **Продолжение после `/clear` и сжатия контекста:** карточка подставляется автоматически.
- **Защита от пустого сохранения:** если не указаны ни следующий шаг, ни то, чего ждём от человека, сохранение отклоняется. Так незаконченная работа не выглядит законченной.

### Параллельные сессии
Включаются в проекте отдельно (см. «Настройка»). После этого:
- каждая сессия работает в своей рабочей копии `.claude/worktrees/<id>` на ветке `claude/<id>`;
- правка файлов в основной копии проекта блокируется с подсказкой завести свою ветку;
- готовая ветка вливается отдельным коммитом слияния, перед ним можно прогнать тесты;
- уборка старых веток обратима: удалённая ветка 30 дней хранится в резервной ссылке.

Командами `wt` управляет сам Claude. Достаточно сказать «заведи отдельную ветку для этой задачи», «влей сессию» или «почисти ветки сессий».

### Барьеры
- **Опасные команды git:** принудительная отправка, `reset --hard`, `clean -f`, удаление ветки, слияние ветки сессии без коммита слияния. Команда разбирается целиком, поэтому текст внутри `echo` не вызывает ложной тревоги.
- **«Готово» без проверки:** если агент изменил файлы и пишет «исправлено», ничего не запустив после правки, его останавливают и просят проверить.
- **Тишина после сохранения:** после итоговой карточки сессии разрешён только блок «продолжаем».
- **Если сломался сам барьер,** действие блокируется, а не проходит молча.
- **Самопроверка при старте:** плагин сверяет, что все его хуки на месте, и молчит, если всё в порядке.

Барьеры действуют только на команды, которые запускает Claude. Ваш обычный терминал они не перехватывают.

### Второе мнение и мост в Codex
- **«Второе мнение»:** Claude пишет самодостаточный вопрос, Codex и Gemini отвечают параллельно, Claude выбирает один ответ и объясняет почему. Без голосования и без «среднего». Режимы: разобрать баг или выбрать подход, собрать свежие факты с поиском в сети, отревьюить текущие изменения, проверить весь проект.
- **«codex проверь diff», «codex ревью», «codex аудит»:** Codex читает проект сам и возвращает риски с файлом и строкой, вердикт GO/NO-GO и уверенность.
- **Codex только читает:** запуск всегда с `-s read-only`, писать в проект он не может.
- **Без молчаливых трат:** по умолчанию работает подписка ChatGPT. Нет входа — Claude попросит выполнить `codex login`; кончилась квота — 45 минут паузы, на платный API только после вашего «да».
- **Без Gemini тоже работает:** нет ключа — отвечает один Codex.

## Настройка

Сессии и барьеры работают сразу после установки. Параллельные сессии включаются файлом `.claude/workflow-kit.json` в корне проекта:

```json
{
  "enabled": true,
  "prefix": "claude",
  "base": "main",
  "worktreeDir": ".claude/worktrees",
  "enforce": "block",
  "linkFiles": [],
  "testCommand": "npm test"
}
```

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `false` | Включает параллельные сессии в этом проекте |
| `prefix` | `claude` | Префикс веток сессий |
| `base` | `main` | Ветка, от которой начинают и в которую вливают |
| `worktreeDir` | `.claude/worktrees` | Где лежат рабочие копии сессий |
| `enforce` | `block` | `block` запрещает правки в основной копии, `warn` только предупреждает |
| `linkFiles` | `[]` | Неотслеживаемые файлы, которые подключаются в каждую рабочую копию ссылкой |
| `testCommand` | пусто | Команда, которая должна пройти перед слиянием |

Осторожно с `linkFiles`: файл, указанный там (например, `.env.local` с ключами), становится доступен во всех параллельных сессиях.

Сохранения вне git-проекта попадают в `~/.claude/workflow-kit/sessions/`.

Второе мнение настраивается переменными окружения в оболочке, из которой запускается Claude Code. Ключи берутся только оттуда, из файлов плагин их не читает.

| Переменная | Что делает |
|---|---|
| `GEMINI_API_KEY` | Включает Gemini вторым голосом (ключ из Google AI Studio) |
| `AWK_GEMINI_MODEL` | Модель Gemini, по умолчанию `gemini-pro-latest` |
| `AWK_CODEX_MODEL` | Модель Codex для оценки изменений и обычных вопросов, по умолчанию `gpt-5.6-terra` |
| `AWK_CODEX_MODEL_DEEP` | Модель Codex для ревью и аудита, по умолчанию `gpt-5.6-sol` |
| `OPENAI_API_KEY` | Нужен только для платного запуска мимо подписки, после вашего согласия |

## Экстренный обход барьера

- Опасную команду git вы запускаете сами в своём терминале.
- Разовая правка в основной копии: переменная окружения `WT_ALLOW_MAIN=1`.
- Временное отключение барьера: файл `~/.claude/workflow-kit/run/guard-bypass/<имя>` со строками `expires_at=<unix-время>` и `reason=<зачем>`. После срока обход перестаёт действовать сам.

## Тесты

```
bash tests/run-all.sh
```

Каждый барьер покрыт тестами на блокировку и на пропуск. Мост в Codex проверяется без сети, на подставных `codex` и `curl`: режим только для чтения, ключ не утекает в вызов по подписке, сбои распознаются верно. Тесты проверены на то, что умеют падать: решающую строку ломали нарочно и смотрели, что тест краснеет.
